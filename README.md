# shihtiy.com

Personal blog built with Jekyll and the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme gem (chirpy-starter layout).

- Content: `_posts/`, `_tabs/`, `assets/img/`
- Site config: `_config.yml`
- Theme overrides (AdSense slots, favicons, share/contact): `_layouts/`, `_includes/`, `_data/`

Upgrade the theme with `bundle update jekyll-theme-chirpy`; only the override files above need a manual diff against the new theme version.
